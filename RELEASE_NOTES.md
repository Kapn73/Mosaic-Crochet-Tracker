# Release notes

## PDF + JSON public release

- Added direct local import of default two-color Stitch Fiddle mosaic crochet PDFs
- Retained compatible JSON import
- Added automatic left/right orientation correction for PDF imports
- Added optional converted JSON download
- Retained multiple projects, variable segment sizes, Retina rendering, and progress tracking
- Retained full-library backup and restore
- Added public-facing privacy, iPhone, deployment, and troubleshooting documentation

The PDF importer processes selected files locally in the browser. No pattern PDF or converted chart is uploaded by the application.

MOSAIC CROCHET PROJECT VIEWER — STABILITY & MOBILE RELEASE

For users:
1. Open index.html through a hosted HTTPS site such as GitHub Pages.
2. Select New Project.
3. Import a supported Stitch Fiddle PDF or compatible JSON.
4. Confirm the preview, then create the project.
5. On iPhone, select Crochet Mode and add the site to the Home Screen.
6. Download regular full-library backups.

For GitHub Pages:
Upload every file and folder in this package to the repository root.
Keep vendor/, icons/, tests/, .github/, and .nojekyll.
Enable Pages from main / root.

See README.md for the full public guide.
